The things I use to make my life easy
### Mac apps:
- [LinearMouse](https://linearmouse.app/en/) - open source app to make my mac trackpad and external mouse scroll smoothly
- [Flux](https://justgetflux.com/) - to make my eyes have less strain when working through night
- [AltTab](https://alt-tab.app/) - windows like tab previews when doing alt + tab. Free version is more than enough
- Sideloadly - load ipas
- AeroSpace - great window utility to manage spaces/windows. Haven't gotten used to it yet
- Barbee - menu bar manager (after using Bartender 6 for a while). I bought a $6 license for year
- Beekeeper Studio - best DB manager. Love it all the way <3
- Bear - Note taking app. free version is sick but bought a student discount year subscription just to sync notes. 
- Bitwarden - free password manager
- Cursor - IDE
- DaVinci Resolve - video editor
- Arc - browser (pretty disappointed that they are letting it go)
- Orbstack - docker desktop alternative. Love itttt
- Ghostty - terminal
- Handbrake - video compressor
- IINA - video and audio player. Free and excellent UI. kinda beats VLC
- iMazing - manage ios devices
- Linear - ticket tracking
- LocalSend - transfer files across devices
- LosslessCut - trim audios/videos super fast
- MarkEdit and Marked - markdown viewer
- MonitorControl - control external monitor brightness. Downside - either flux or this will work at a time
- Obsidian - managing my website blog + note taking
- Notion - note taking + alot more
- PDF Expert (by Readdle) - PDF viewer and editor
- RasterFox - image optimizer
- Alfred - Alternative to spotlight. Also use its clipboard manager. have tried Raycast but have come back to alfred as im accustomed to it.
- Wispr flow - audio to text (use superwhisperer to load an offline free modal as an alt)
- Tor browser
- XnViewMP - image viewer
